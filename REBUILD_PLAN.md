# ALIVE — Rebuild Plan

## North star

A beautiful digital place where intelligence can have a recognizable presence.

## Principle

The face must carry the illusion before the interface does.

## Architecture

### Character
The woman is rendered as a layered 2.5D composition from the original clean portrait. Important features are independent visual layers rather than one flat bitmap.

### Motion
A single animation loop handles gaze interpolation, blinking, expression interpolation, breathing, subtle head motion, and speech rhythm.

### States
Idle, attentive, listening, thinking, speaking, warm, curious, playful.

### World
Use the real photographic room as the environment. Add only restrained overlays that reinforce depth or mood.

### Interaction
Pointer -> gaze. Typing -> attention. Voice -> speaking. Silence -> idle presence.

### Mind
Keep conversation independent from the visual architecture. Local behavior first; server-side intelligence later.

## Build order

1. Character layers.
2. Eye / iris tracking.
3. Blink.
4. Breathing and head motion.
5. Expression transitions.
6. Cinematic UI.
7. Voice.
8. Mind.
9. Advanced 2.5D only after the first eight are visually excellent.

## Non-goals

No dashboard, no gamified pet, no constant decorative animation, no whole-image parallax pretending to be embodiment.
